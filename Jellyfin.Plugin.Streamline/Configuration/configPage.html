New media

However a movie or show arrives (Radarr/Sonarr after a Seerr request, or copied in by hand), Jellyfin's library scan fetches its metadata from TMDb. Brand-new releases often don't have a trailer or keywords there yet, though. With this on, 15 minutes after a title is added anything still missing is fetched again, and the daily task "Fill in missing genres and trailers" (Dashboard > Scheduled Tasks) keeps retrying recent additions. It only fills gaps; nothing already there is replaced. Needs TMDb enabled as a metadata downloader for the library (and OMDb for Rotten Tomatoes scores).
Trailers come from TMDb, and for titles TMDb has none for, from KinoCheck (free, no key). With a YouTube Data API key (Google Cloud console, free tier), titles neither has get a YouTube search as a last resort. Found trailers are saved into the title's own metadata; users can't change them.
Compares each movie and show with its folder name and year (what Radarr/Sonarr or you named it). When Jellyfin's match doesn't fit (another name and year, or no match at all), it's looked up again and re-identified if exactly one result clearly fits, like using Identify by hand. Missing posters are fetched again. Runs on new titles and daily ("Fix wrong titles and posters"). Locked titles are never touched; anything uncertain, or still wrong after an automatic fix (checked again about 10 minutes later), is listed below to fix by hand.

Seerr

Requests made in Seerr (Jellyseerr or Overseerr) go on the requester's Watch List as soon as they're in Jellyfin.

Requesters are matched to Jellyfin users by their linked Jellyfin account (Jellyseerr) or user name. Each request is added once (removing it from the Watch List sticks), including requests made before this was connected.
Seerr: Settings > General > API Key.

Advanced

Adds a small button at the bottom left that opens the current page in a phone-sized frame, laid out the way a phone gets it, so the phone layout can be checked from a computer. Visible to everyone while on; meant for testing.
With the phone preview button on, admins also get a User view button: it opens the site signed in as this account (its own Watch List, Favorites, ratings and menus), in a frame on top of the page, without signing you out. Uses Jellyfin's Quick Connect (Dashboard > General), which has to be on. Pick a test account, not someone's real one: you'd see their lists.
How the home screen's script gets loaded into the web client. Automatic tries the File Transformation and JavaScript Injector plugins first (if installed), then falls back to patching index.html directly. Changing this takes effect after a server restart.
